## 🚀 Como Executar

```bash
# Clone o repositório
git clone https://github.com/seu-usuario/ArmsTrack.git

# Entre na pasta
cd ArmsTrack

# Instale as dependências
pip install pandas plotly nbformat

# Abra o notebook
jupyter notebook ArmsTrack.ipynb
```
